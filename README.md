# Shap

A full-stack web application project combining React frontend with backend services. This repository contains an animated, interactive web application built with modern web technologies.

## 📋 Project Structure

```
Shap/
├── Backend/          # Backend services
├── shegal/           # React frontend application
├── package.json      # Root dependencies
└── package-lock.json
```

## 🛠️ Tech Stack

### Frontend (shegal/)
- **React** 19.2.3 - UI library
- **React Router** 7.9.1 - Client-side routing
- **Tailwind CSS** 3.4.19 - Utility-first CSS framework
- **Framer Motion** 12.23.26 - Animation library
- **Lucide React** 0.562.0 - Icon library
- **Axios** 1.11.0 - HTTP client
- **Crypto-js** 4.2.0 - Encryption utilities

### Build Tools
- **React Scripts** 5.0.1 - Create React App tooling
- **PostCSS** 8.5.6 - CSS transformations
- **Autoprefixer** 10.4.23 - CSS vendor prefixing

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/samarpanpdl/Shap.git
cd Shap
```

2. Install dependencies:
```bash
cd shegal
npm install
```

3. Start the development server:
```bash
npm start
```

The application will open at `http://localhost:3000`

## 📝 Available Scripts

In the `shegal` directory:

- `npm start` - Runs the app in development mode
- `npm build` - Builds the app for production
- `npm test` - Runs the test suite
- `npm eject` - Ejects Create React App configuration (irreversible)
